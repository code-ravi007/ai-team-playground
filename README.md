# AI team playground

A small test project for the AI company team
([code-ravi007/ai-company-agents](https://github.com/code-ravi007/ai-company-agents)).
It's a tiny to-do list web page, so the agents have something real to build on.

## Run it

Open `index.html` in a browser. No build step.

## Test it

```
node --test
```

Needs Node 18 or newer. There are no dependencies.

## Ask the team for work

Open an issue that describes what you want, then add the `ai:build` label.
The team plans, builds, reviews and tests it, then opens a pull request for you to merge.
